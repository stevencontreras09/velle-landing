# ✨ VELLÉ — Belleza • Moda • Accesorios

Landing page moderna y responsiva de lujo para **Vellé**, diseñada para presentar el catálogo oficial de campaña de Belcorp ([ElizabethPichardo14](https://catalogo.somosbelcorp.com/do/ElizabethPichardo14)), colecciones de fragancias, maquillaje, cuidado facial y accesorios finos.

---

## 🎨 Características

- **Diseño de Lujo**: Paleta inspirada en mármol blanco, oro champagne (`#C9A84C`) y detalles de perla.
- **Modo Claro / Modo Oscuro**: Alternancia de temas con persistencia en `localStorage`.
- **Catálogo Interactivo**: Enlaces directos y vistas previas del catálogo de campaña actual.
- **Productos Destacados**: Filtros en tiempo real por categorías (Fragancias, Cuidado Facial, Maquillaje, Joyería).
- **Asesoría por WhatsApp**: Botón flotante y formulario con mensajes dinámicos para consulta rápida.
- **100% Responsivo**: Adaptado para móviles, tablets y pantallas de escritorio.

---

## 🛠️ Tecnologías Utilizadas

- **HTML5 Semántico**: Estructura accesible y optimizada con OpenGraph y metadatos SEO.
- **CSS3 Moderno**: Variables CSS, efectos Glassmorphism, animaciones Shimmer y diseño Mobile First.
- **JavaScript (Vanilla)**: Lógica de cambio de tema, menú drawer móvil, filtrado interactivo y scroll reveal.
